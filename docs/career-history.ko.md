- 구성요소별 구현·검증 기록을 확보함. 전체 기능을 연결한 운영 검증과 실제 고객 업무 효과 확인은 남아 있음.

사용 기술: Rust, Python, TypeScript, PostgreSQL, Docker, GitLab. [상세 설계·구현 상태](projects/project-reliability.md)

**뉴스 요약 품질 자동 평가 | Plantynet**

2026.01~2026.07 · 2명 팀에서 평가 기준, 자동 처리, 데이터 저장, 정기 실행 담당

약 60만 건 규모의 뉴스 요약을 같은 기준으로 확인해야 했음. 요약의 내용·날짜·허위 정보·문체·형식을 각각 평가하면 AI 호출이 반복되는 문제가 있었음.

- 품질 기준 5개를 한 번의 AI 평가 요청에 묶어 점수와 판단 이유를 받도록 구현함. 정상 응답 여부와 원문 대비 요약 길이는 코드로 계산함.
- 이미 처리한 결과를 건너뛰고 실패한 작업을 재시도하며 같은 작업이 중복 실행되지 않도록 구성함. 평가 결과 저장과 일일 보고서 작성을 자동화함.
- 기준별 평가 요청을 5회에서 1회로 묶는 구조를 구현함. 호출 수 감소를 비용 절감률이나 품질 유지의 측정값으로 해석하지 않음.

사용 기술: Python, deepeval/GEval, PostgreSQL, openpyxl, cron, flock.

## 추가 프로젝트

**스미싱 URL 탐지 | Plantynet**

문자 사기에 쓰이는 URL을 찾는 모델과 성능 확인 기능을 개발함. URLBert를 사내 데이터로 추가 학습함. 정상·스미싱 URL 비율이 같은 1:1 평가에서 기존 Random Forest의 F1 58.02% 대비 96.10%를 기록함. F1은 오탐과 누락을 함께 반영하는 지표임. 연결된 웹페이지의 HTML 특징 17개를 분석하는 별도 경로도 구현함.

사용 기술: Python, URLBert, Hugging Face Transformers, HTML 분석. 개별 수행 기간 미확인.

**매거진 검색·추천 AI 챗봇 | Plantynet**

AI 파트 2명 중 검색·데이터 정리·AI 처리 로직을 담당함. 키워드와 문장 의미를 함께 검색하고 검색 결과의 순서를 다시 정해 답변에 연결함. 약 15만 개의 문서 조각에서 검색에 부적합한 약 1.8만 개를 제외했으며 입력·답변의 안전성 검사도 구현함.

사용 기술: Python, Milvus, BGE-M3, BM25, BGE-Reranker, LlamaGuard. 개별 수행 기간 미확인.

**뉴스 요약·분류·태깅 API | Plantynet**

3명 팀에서 AI 처리 로직과 서비스 연결 기능의 설계·개발·배포를 담당함. 기사 요약·분류·태그 추출을 자체 AI 모델로 처리하도록 전환함. 요약 길이 조정, 긴 문서 축약, 실패 시 재시도와 검토 화면을 구현함.

사용 기술: Python, FastAPI, vLLM, LangGraph, Gradio, Docker. 개별 수행 기간 미확인.

**Skylife 영화 추천 API | AIO2O**

2023.06~2023.12 · 4명 팀에서 추천 로직과 검색용 데이터 저장소 설계를 담당함. 장르·배우 조건으로 후보를 좁히고 영화 설명의 의미를 비교해 추천 순서를 정하도록 구현함. 추천 기능을 다른 서비스에서 호출할 수 있는 API로 개발·배포함.

사용 기술: Python, PostgreSQL, pgvector, Embedding Models, Docker.

**MarketScope AI 상권 분석 | 개인 프로젝트**

2026.01 시작 · 기획, 데이터 정리, 화면, 서버, AI 기능을 1인 개발함. 서울시 1,650개 상권 자료를 지도와 대화형 분석에 연결함. AI가 11종 분석 도구를 골라 사용하고 지도·대화에 결과를 표시하도록 구현함. v0.4.0 공개 이력이 있으며 상세 상태는 2026.09 공개 기록 기준임.

사용 기술: Python, FastAPI, LangGraph, PostgreSQL/PostGIS, React, TypeScript.
