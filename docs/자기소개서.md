# 자기소개서

> **김선준**    1994년생 | 남성
> "데이터가 흐르는 길을 만들고, 그 위에서 Agent를 굴리는 엔지니어"
>
> UNIST에서 추천 시스템을 연구했습니다. 사용자 선호를 벡터로 바꾸고 유사도로 찾는 작업을 하다 보니, 자연스럽게 벡터 DB와 임베딩 검색 쪽으로 넘어왔습니다. 졸업 후에는 Skylife 영화 추천, 부산관광공사 여행 챗봇(현재 상용 운영 중)처럼 벡터 검색 기반 서비스를 만들었고, 이후 vLLM 서빙, Agentic RAG, Reflexion Agent까지 작업 범위를 넓혀 왔습니다. 모델 하나 띄우는 게 아니라, 데이터 수집부터 전처리, 벡터화, 검색, 생성, 서빙까지 직접 손대는 편입니다.
>
> [개발 전략]
> 1. **파이프라인 전 구간에 책임지기**: 전처리에서 병목이 터지면 모델이 아무리 좋아도 소용없습니다. 데이터 수집, 임베딩, 검색, 서빙 — 어느 한 구간이 빠져도 서비스가 안 되기 때문에, 전 구간을 직접 챙깁니다.
> 2. **데이터 품질이 모델 성능을 결정한다**: 같은 RAG 구조라도 청크를 어떻게 자르고, 어떤 메타 정보를 붙이느냐에 따라 검색 정확도가 달라집니다. 100자 이하 청크 필터링, KoNLPy 토큰 검증 같은 작업을 전처리 단계에서 잡아둡니다.
> 3. **실패에서 배우는 Agent 설계**: 에이전트가 한번 틀렸다고 같은 실수를 반복하면 안 됩니다. Reflexion 패턴으로 실패 원인을 기록하고 다음 시도에 반영하는 구조를 직접 만들어서 쓰고 있습니다.
> 4. **프로토타입에서 서비스까지의 간극 메우기**: LlamaGuard로 입출력 안전 검증, SSE 스트리밍으로 실시간 응답, 비동기 처리로 동시 요청 관리 — 연구 코드를 서비스로 올리려면 이런 작업이 반드시 따라옵니다. 그 작업을 귀찮아하지 않습니다.

## 학력

UNIST(울산과학기술원) 산업공학과 석사 (2023 졸업)

석사 논문으로 Convolutional Autoencoder 기반 추천 시스템을 연구했습니다. 사용자 선호를 잠재 벡터(latent vector)로 표현하고, 그 벡터 간 유사도로 아이템을 추천하는 구조입니다. 이때 익힌 임베딩-검색 파이프라인이 졸업 후 pgvector, Milvus를 다루는 데 그대로 이어졌습니다.

논문: *Personal recommender system via convolutional autoencoder with conditioning augmentation*
