# 자기소개서

---

## 1. 지원자 소개

안녕하세요. UNIST(울산과학기술원) 산업공학과 석사 출신 **AI/백엔드 엔지니어 김선준**입니다.

LLM 기반 AI 서비스 개발 경험을 보유하고 있으며, vLLM, LangGraph, RAG 시스템 구축부터 데이터 파이프라인, API 서비스까지 End-to-End 프로젝트 경험이 있습니다.

---

## 2. 핵심 역량

| 역량 | 프로젝트 경험 |
|------|-------------|
| **LLM 서비스 개발** | vLLM 기반 텍스트 처리 API, LangGraph 에이전트 개발 경험 |
| **RAG 시스템** | Milvus 벡터DB, 하이브리드 검색, Reranking 적용 경험 |
| **데이터 파이프라인** | 서울시 Open API 자동 수집, DB 스키마 설계 경험 |
| **API 서비스** | FastAPI 기반 비동기 처리, SSE 스트리밍 구현 경험 |

---

## 3. 주요 프로젝트

### [실서비스] 부산관광공사 여행 챗봇
- 자연어 질의 기반 여행지 추천 시스템
- 벡터 DB 구축 및 메타 필터링 + 유사도 검색 결합 알고리즘
- **현재 상용 서비스 운영 중**

### [AI 에이전트] Reflexion Agent
- LangGraph 기반 ReAct + Reflexion 패턴 자기개선형 에이전트
- 실패 시 원인 분석 → 교훈 학습 → 재시도 메커니즘
- 다중 LLM(Gemini, OpenAI, Anthropic) 전환 지원

### [RAG 시스템] Agentic RAG 챗봇
- Milvus 기반 하이브리드 검색 (Dense + BM25 Sparse)
- BGE-Reranker 적용 검색 정확도 향상
- LlamaGuard 기반 입출력 안전성 검증

### [API 서비스] AI_LLM_API
- vLLM 엔진 in-process 구동
- 기사 요약, 주제 분류, 키워드 추출 API
- 목표 길이 수렴 알고리즘 (70~130% 범위 내 수렴)

### [사이드 프로젝트] 서울 상권분석 시스템
- 서울시 Open API 8개 상권 서비스 자동 동기화 파이프라인
- LangGraph 기반 Tool Calling Agent로 PostgreSQL 동적 검색

## 4. 기술 스택

- **Language**: Python
- **LLM/AI**: vLLM, LangGraph, LangChain, OpenAI API, HuggingFace
- **Vector DB**: Milvus, pgvector
- **Backend**: FastAPI, Uvicorn
- **Database**: PostgreSQL, Oracle, MySQL
- **Infra**: Docker, Docker Compose
- **Embedding**: BGE-M3, BGE-Reranker
